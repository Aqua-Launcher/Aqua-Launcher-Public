Horizon · Rust Edition

Horizon, installed
by Aqua.

Horizon is the open-source Rust rewrite of Minecraft: Java Edition 26.3. Aqua downloads the official client, provisions the Minecraft and Java files it pins, runs Horizon's bundled preparer, then starts the Rust game directly — no Horizon launcher involved.

  • Official builds, checksum-verified. Aqua pulls the Windows, macOS, or Linux release from horizon-rust/horizon and checks its SHA-256 before unpacking.
  • One Play target. Point the dashboard's Play button at any installed Horizon build, or start a specific build from its row.
  • Its own home. Builds, downloads, and worlds live in Aqua's data folder. Horizon's launcher folder is never read.
  • Your copy still matters. Horizon's preparer reads Minecraft: Java Edition files that Aqua installs, so you still need your own game copy.

Straight answers

The fine print,
in plain sight.

Aqua is deliberately honest about what it does, what needs a workaround, and what is still planned. If something is unclear, the repository's README goes deeper.

Read the README
Do I need a Microsoft account to use Aqua?

No. Aqua starts with an offline profile: enter a player name and play singleplayer, LAN worlds, or modded setups. Microsoft sign-in exists in the backend but is hidden in the UI while the Azure application is pending Mojang approval. Offline profiles cannot join online-mode servers.

Can I play Bedrock from Aqua?

If Minecraft for Windows or Minecraft Preview is installed from the Microsoft Store, yes — Aqua detects it, launches it, and lists its worlds. The Bedrock version browser can download other builds into Aqua's folder. Those are unofficial copies of Store packages: APPX builds need Developer Mode, MSIXVC builds replace the running copy, and the Store may overwrite either on its next update. Back up worlds before switching.

Does Aqua support Horizon?

Yes. Installations → Horizon downloads Horizon's official Rust build, verifies its SHA-256, provisions Minecraft 26.3 and the Java runtime it pins, and runs Horizon's own preparer. Play starts the Rust client directly; the Horizon launcher is not involved. You still need your own Minecraft: Java Edition copy, and Horizon launches have no playtime or crash capture in Aqua.

What happens when I delete an installation?

Only the profile entry is removed. Its game directory — worlds, mods, resource packs, and downloaded files — stays on disk. Backups live in the launcher data folder, so they survive profile edits too.

Where does Aqua keep my files?

On Windows, everything lives under %APPDATA%\Aqua Launcher: launcher.json for settings and profiles, minecraft/ for shared versions and assets, instances/ for game directories, runtime/ for Java, logs/ for output, and backups/ for world archives. Custom game folders are checked against drive roots and protected system locations.

Does Aqua send telemetry?

No telemetry, analytics, ads, or background uploads. Network calls are limited to what you ask for: Mojang manifests and game files, Java runtimes, Modrinth content, server pings, and — for Bedrock — the Store build catalogue.

What about older versions and Java 8?

Minecraft 1.12.2 and older need Java 8. Aqua will not substitute a newer runtime; install Java 8 once from Settings → Java → Official runtimes and those profiles pick it up automatically.

Does it run on macOS and Linux?

The architecture is cross-platform and DMG/AppImage targets are configured, but Windows 10/11 is the primary and only actively tested platform. Bedrock support is Windows-only.
